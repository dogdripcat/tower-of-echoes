# Tower of Echoes — Female Character Art Direction Guide

버전 2.13 · 2026-10-10 · PC 전용 · 시각 분석 및 제작 기준 문서

## 적용 범위와 기준의 우선순위

플레이어블, 보스, 성역 NPC의 여성 캐릭터를 하나의 작화 체계로 제작하기 위한 가이드다. 새로운 이미지, 캐릭터 디자인, 게임 기능을 제작하는 단계가 아니다. 기존 의상·얼굴·헤어·장비의 정체성을 유지하면서 골격, 자세, 머리카락의 배치와 렌더링을 일관되게 교정한다.

우선순위는 **캐릭터별 승인 원본 → 승인된 플레이어블·성역 NPC의 공통 작화 언어 → 본 가이드 → 외부 헤어/포즈/표정/의상/신체 자료**다. 외부 자료의 얼굴, 체형, 의상, 사진 질감을 그대로 옮기지 않는다.

이번 검토에서는 현재 작업본의 `dist/assets/hero-*-final-v5.webp` 7개, `npc-*-cutout-v1.png` 7개, 보스 기본 일러스트 5개를 시각적으로 비교했다. 이 파일들은 현재 작업본 기준 자료이며, 파일명만으로 최신 승인 날짜와 승인 여부를 확정하지 않는다. 승인 원본이 별도로 지정되면 해당 원본을 우선한다. 실측하지 않은 등신·골격 비율을 확정 수치로 기록하지 않는다.

헤어 자료 11개에 대한 분석 기록이 있다. 2026-10-09 추가 첨부된 포즈/인체 자료 4장을 직접 확인하여 P01–P04의 원본 식별자, 관찰 구조, 적용 범위와 제한을 기록했다. v1.1까지의 포즈 자료별 분석 누락은 이번 4장에 한해 보완되었다. 과거 다른 자료의 반영까지 확인했다고 확대 해석하지 않는다. 일반 포즈 규칙과 비어 있는 수용 카드는 자료별 분석 완료의 근거가 아니다.

### 사용자 정정 — 여관주인 우선 기준과 이미지 작업 보류 (v1.7)

2026-10-09 사용자는 현재 여관주인 `dist/assets/npc-innkeeper-cutout-v1.png`만 요청한 방향을 반영한 일러스트라고 지정했다. 이후 보스의 작화·신체 체적·의상 핏·마감 기준은 이 여관주인을 최우선으로 사용한다. 다른 플레이어블/NPC와 기존 보스 리마스터·설정화는 승인된 공통 기준으로 확정하지 않는다. 캐릭터 정체성은 보스별 지정 원본을 보존하되, 작화와 체적의 판단에는 이번 정정을 우선한다.

| 사용자 지적 | 보스별 후속 수정 규칙 | 검수 기준 |
|---|---|---|
| 여관주인처럼 똑바로 서 있지 못함 | 기본 검토 자세는 몸통을 곧게 세우고 흉곽–골반–척추를 연결한다. 불필요한 기울임·허리 꺾임·다리 꼬기를 줄인다. 장비 하중과 지지 다리를 명확히 한다 | 전신 중심축, 어깨·골반 균형과 접지 확인. 기존 부유 정체성이 있는 보스는 몸통축을 정돈하되 접지를 임의로 강요하지 않음 |
| 의상이 신체에 올바르게 맞지 않음 | 신체를 먼저 정리한 뒤 기존 의상 치수·판금 위치·벨트·소매·치마를 그 체적에 맞춘다. 천 여유분과 당김점, 갑옷 두께·관절 공간을 구분한다 | 의상이 몸을 잘라내거나 관통하지 않고 기존 형태·색·노출 범위를 유지하는지 확인 |
| 신체가 빈약하고 원하는 사이즈와 다름 | 여관주인의 충분한 흉부·몸통 체적과 자연스러운 연결을 비교 기준으로 삼아, 보스의 빈약한 체적을 개선한다. 흉부만 독립 확대하지 않고 흉곽·허리·골반·허벅지 연결을 함께 정리한다 | 원하는 체적감과 캐릭터별 체형 차이를 함께 비교. 숨겨진 하체·수치 비율을 여관주인 이미지에서 실측했다고 단정하지 않음. 5명을 동일 체형으로 복제하지 않음 |
| 불필요한 장신구가 많음 | 원본의 핵심 상징 장식과 장비는 유지한다. 생성 과정에서 늘어난 장식·중복 체인·불필요한 부속은 줄이고 얼굴·신체·의상 구조를 가리지 않게 정돈한다 | 원본에 없는 추가 장식 여부와 실루엣 혼잡도 확인. 정체성에 필요한 장식의 자의적 삭제 금지 |
| 리터치가 많아 단정하지 못함 | 여관주인의 정돈된 윤곽, 큰 명암 면, 절제된 피부·천 표현을 우선한다. 과도한 잔선·하이라이트·광택·덧무늬를 줄여 단정한 마감으로 정리한다 | 얼굴·손·몸통·의상 주름이 축소 상태에서도 읽히는지, 소재가 과세부 없이 구분되는지 확인 |

이 다섯 항목은 아르델라·로제벨·아스트라·모르가나·이벨린에 공통 적용한다. 보스별 얼굴·헤어·색·기본 의상·무기·상징은 각각 보존한다. 기존 생성 설정화는 후속 수정을 위한 검토본이며 최종 리마스터 또는 승인 원본으로 취급하지 않는다.

**진행 제한:** 사용자께서 별도로 이미지 생성을 지시할 때까지 새 이미지 생성·기존 이미지 수정·다음 보스 자동 제작을 중단한다. 현재 단계는 문서 기준 반영만 수행한다. 게임 코드 수정·GitHub Push·Cloudflare Deploy는 수행하지 않는다.

### 사용자 추가 지시 — 신체 자료 기반 사이즈와 보스별 내부 의상 점검 (v1.8)

2026-10-09 사용자는 신체 사이즈의 기준을 제공한 신체 자료에서 찾고, 각 보스의 속옷·가터벨트·스타킹도 점검하도록 지정했다. B01–B12와 보스별 지정 원본을 재비교했다. 여관주인은 작화·핏·정돈의 최우선 기준, B 자료는 부위별 체적과 상대 비율의 기준으로 역할을 구분한다.

- **사이즈 적용:** B01·B02·B06·B09·B12의 풍부한 흉부/몸통을 비교하고, B03·B04·B05의 골반–허벅지–무릎–종아리 연결을 함께 사용한다. B07·B08·B10은 측면 깊이·팔 연결·원근 효과의 보조 기준이다. B11의 강한 만화적 체적은 프로젝트 전체에 그대로 복제하지 않는다. 부위별 자료를 한 캐릭터의 체형으로 조합할 때 골격과 전신 연결을 다시 확인한다.
- **기록 방식:** 지정 참고 자료의 해당 부위와 보스의 동일 시점을 비교해 상대 크기·깊이·연결을 기록한다. 가슴·골반·허벅지를 독립 항목으로 기록하되 보정 후 전신 균형을 확인한다. 제공 이미지에 적혀 있지 않은 cm·컵·의류 호수·1–100 값을 실제 측정값처럼 만들지 않는다. 이번 자료를 모든 보스에 동일 비율로 복사하거나 보스 간 체형 순위를 임의로 확정하지 않는다.
- **내부 의상 점검:** 속옷과 외부 코르셋/갑옷 밑옷을 구분한다. 가터벨트(허리 지지부), 세로 가터끈, 독립 허벅지띠, 스타킹 상단, 장식 체인/갑옷 고정끈을 구분한다. 원본에서 가려진 속옷·여밈·허리 고정점은 확인 불가로 남기며 신규 디자인을 제작하지 않는다.

| 보스 | 원본에서 확인한 의상 구조 | 후속 핏·연결 점검 | 확인 불가 항목 |
|---|---|---|---|
| 아르델라 | 판금 아래 검정 밑옷, 허벅지의 갈색 버클띠와 갑옷 | 증가한 신체 체적에 맞는 밑옷/판금 공간, 허벅지띠 접촉과 관절 이동. 갑옷 고정띠를 속옷 가터로 혼동하지 않음 | 별도 브라·하의·가터벨트·스타킹 유무 및 내부 지지 구조 |
| 로제벨 | 외부 코르셋형 상의, 레이스 상단의 검정 반투명 다리 착장, 허벅지 장식띠/연결 일부, 금색 가시 장식 신발 | 컵형 패널과 흉부의 핏, 상단 레이스 폭/높이, 피부 접촉, 보이는 끈의 경로. 별 장식·체인과 지지끈 구분. 전체 허리형 가터가 보인다고 단정하지 않음 | 별도 내부 브라·하의, 가려진 허리벨트·클립 및 뒤쪽 연결 |
| 아스트라 | 코르셋형 몸통, 레이스 상단 검정 스타킹, 허벅지띠와 연결 장식/체인, 금색 끈 구두 | 흉부 패널·허리 핏, 스타킹 상단 높이/투명도, 띠의 곡면 접촉, 연결부가 실제 지지끈인지 장식인지 판독. 회중시계 사슬과 가터 연결 구분 | 내부 속옷·허리형 가터벨트·가려진 상부 고정 및 후면 클립 |
| 모르가나 | 몸통에서 다리로 이어져 보이는 검정 시스루 착장, 발목 주변 끝단/고리, 맨발 | 몸통–골반–허벅지의 원단 연속성, 투명도와 두께, 소매/겉옷과 겹침. 별도 스타킹·가터로 임의 분할하지 않음 | 실제 패턴의 일체형 여부, 내부 브라·하의와 숨은 여밈, 별도 가터 유무 |
| 이벨린 | 흰/검/보라 긴 겹옷과 허리 지지부, 하체 대부분 가림 | 강화한 체적에 맞는 상체·허리 재단, 안감/겉감 겹침과 자락 두께. 겉옷 장식 사슬을 가터로 해석하지 않음 | 속옷·가터벨트·스타킹·허벅지띠의 유무와 구조 전반 |

스타킹이나 밴드가 확인되는 부분은 C21–C40 규칙에 따라 허벅지 곡면·레이스/망사/불투명 재질·클립/끈의 접촉을 점검한다. 눌림은 기존 자료의 약한 단차 또는 뚜렷한 굴곡을 비교하되 실제 압력·변형량으로 수치화하지 않는다. 이번 점검은 관찰 및 후속 수정 기준 기록이며, 의상 핏이 최종 QA를 통과했다는 뜻은 아니다. 별도 지시 전 이미지 생성·수정 중단은 계속 유지한다.

### 보스별 내부 의상 신규 설정안 — 사용자 요청에 따른 설계 (v1.9)

2026-10-09 사용자가 각 보스의 속옷과 숨은 구조를 새로 설정하도록 요청했다. 아래는 **원본에서 확인한 사실이 아닌 신규 설계안**이다. v1.8의 내부 의상 신규 설계 보류는 이번 명시 요청 범위에서 해제한다. 이미지 생성·수정 보류와 겉옷 디자인 보존은 유지한다. 기존 관찰표의 ‘확인 불가’는 원본 판독 결과로 남기며, 아래 설정안과 혼동하지 않는다.

공통 원칙: 성인 여성 캐릭터의 의복 구조 설정이다. 지정 신체 자료의 체적을 먼저 반영하고 그 신체에 맞춰 속옷을 재단한다. 컵·밴드·가터로 신체를 빈약하게 압축하거나 체적을 인위적으로 부풀리지 않는다. 속옷 장식은 최소화하고 후크·클립은 피부와 갑옷 사이에 보호 덮개를 둔다. 끈 길이는 실제 자세·허벅지 곡면에 맞춘다. 압박 표현은 국소의 완만한 단차와 접촉 그림자로 정리하며 다리 골격이나 전체 체적을 변형하지 않는다. 겉옷 밖으로 새 속옷·끈·노출이 추가되지 않도록 숨은 경로를 설계한다.

**1F 아르델라 — 갑옷 안쪽의 실용적 지지 세트**
- 상의: 무광 짙은 남색의 풀컵 롱라인 브라. 넓은 어깨끈과 부드러운 밑가슴 밴드로 흉부를 지지한다. 단단한 장식·두꺼운 패드 없이 얇은 안감과 컵 봉제로 체적을 수용한다.
- 하의: 같은 남색의 하이웨이스트 짧은 드로어즈. 사타구니·골반 관절은 부드러운 연결 패널로 구성한다.
- 가터: 별도 얇은 직물 허리벨트에서 각 다리에 앞/뒤 2개씩 총 4개 끈을 내려 검정 불투명 허벅지 스타킹을 고정한다. 겉의 갈색 갑옷 고정띠와 독립된 구조로 둔다.
- 스타킹/접촉: 매끈한 상단띠와 갑옷 밑 마찰 보호용 원단. 레이스·매달린 금속 장식 없음. 허벅지 접촉은 약한 단차.
- 숨은 구조: 브라 뒤 여밈은 등판 안감 아래, 가터 여밈은 옆쪽 덮개 아래. 스타킹 클립과 조절부는 판금 연결부를 피하며 검정 밑옷 안쪽에 배치한다.

**2F 로제벨 — 코르셋 안쪽의 검정·적색 레이스 세트**
- 상의: 외부 코르셋에 봉제한 검정 소프트 컵과 밑가슴 지지 테이프. 별도 두꺼운 브라를 겹쳐 체적이 밀리게 하지 않는다. 가장자리에 적색 장미 레이스를 소량 배치한다.
- 하의: 검정 안감 있는 브리프, 옆선에만 적색 레이스. 기존 드레스의 노출 범위 밖으로 나오지 않는다.
- 가터: 코르셋 하단 안쪽에 고정하는 탈착식 검정 허리 가터벨트, 총 4개 조절끈. 숨은 세로끈은 기존 허벅지 장식 위치와 겹침을 피하고 레이스 스타킹 상단에 연결한다.
- 스타킹/접촉: 기존 검정 반투명 스타킹과 장미 레이스 상단 유지. 작은 무광 금색 클립, 완만한 국소 눌림. 금색 가시 체인은 장식이며 피부를 조이는 지지부로 쓰지 않는다.
- 숨은 구조: 코르셋 뒤 끈 조임에 안쪽 보호 패널, 가터벨트 옆 후크 여밈. 드레스 허리/치마 패널이 상부와 클립 일부를 가린다. 기존 신발 구조는 유지한다.

**3F 아스트라 — 마도사 의상 안쪽의 남색 지지 세트**
- 상의: 검정에 가까운 남색 풀컵 브라, 얇은 안감과 넓은 옆 지지 패널. 어깨끈은 기존 의상 끈 바로 아래 경로로 숨기고, 외부 코르셋과 별도 재단한다.
- 하의: 같은 색의 평평한 봉제선을 가진 브리프. 장식은 좁은 남색 레이스 가장자리로 제한한다.
- 가터: 코르셋 아래의 얇은 독립 남색 허리벨트에 총 4개 조절끈. 작은 무광 금색 조절부/클립으로 기존 검정 레이스 스타킹을 지지한다.
- 스타킹/접촉: 기존 투명도·상단 높이·레이스를 유지한다. 허벅지띠가 원근에 맞게 감싸고 접촉은 약한 단차로 정리한다.
- 숨은 구조: 브라 뒤 후크, 가터벨트 옆 여밈을 겉옷 아래에 숨긴다. 시계·천문 체인은 가터 지지와 분리하며 끈이나 스타킹에 하중을 매달지 않는다.

**4F 모르가나 — 시스루 착장 안쪽의 일체형 지지 구조**
- 상의/하의: 기존 검정 착장 안에 봉제하는 얇은 불투명 지지 바디. 소프트 컵, 밑가슴 밴드, 복부 여유분과 브리프형 하부를 하나로 연결한다. 보라색은 내부 가장자리 봉제에만 제한한다.
- 가터: 별도 가터벨트와 외부 클립은 두지 않는다. 허벅지 상단 안쪽의 부드러운 연결 테이프가 시스루 다리 패널을 지지하는 ‘내장형 지지’로 설계한다.
- 다리 착장/접촉: 몸통에서 다리로 이어져 보이는 기존 시스루 외관을 유지하고 발목 고리와 맨발도 보존한다. 신규 레이스 스타킹 경계를 만들지 않는다. 허벅지의 인위적인 띠 눌림 없음.
- 숨은 구조: 가려지는 옆선에 납작한 여밈과 보호 덮개, 하부 안쪽에 착탈 여밈. 봉제선은 기존 검정 불투명 패널 안에 숨긴다. 겉에서 보이는 시스루 영역의 투명도를 새 안감으로 덮지 않는다.

**5F 이벨린 — 긴 겹옷 안쪽의 아이보리·짙은 보라 세트**
- 상의: 아이보리 풀컵 롱라인 브라, 넓은 어깨끈과 부드러운 옆 지지 패널. 기존 흰 겉옷 아래에 비치는 강한 검정 경계를 피하고 레이스는 가장자리의 가는 선으로 제한한다.
- 하의: 아이보리 하이웨이스트 브리프, 짙은 보라색 내부 안감과 납작한 봉제선.
- 가터: 짙은 보라색 직물 허리벨트, 각 다리 앞/옆/뒤 3개씩 총 6개 조절끈. 긴 겹옷 안쪽에서 스타킹 상단을 지지한다. 겉옷 허리띠와 향로 사슬은 별도 구조로 둔다.
- 스타킹/접촉: 짙은 보라색의 반불투명 허벅지 스타킹, 매끈한 상단띠와 작은 클립. 경계는 완만한 접촉만 표현하고 추가 장식·외부 발광 없음.
- 숨은 구조: 브라 뒤 후크와 가터 옆 여밈은 안감 아래, 조절부와 클립은 얇은 천 덮개로 보호한다. 하부 전체는 기존 긴 겹옷에 가리며 신발·노출·겉옷 실루엣을 새로 확정하지 않는다.

설계 상태: 5종 모두 텍스트 검토용 신규 설정안. 원본 증거·최종 의상 승인·생성 이미지가 아니다. 후속 수정이 가능하며, 별도 이미지 생성 지시 전까지 이미지를 만들지 않는다.

### 내부 의상 소재·레이스·꽃무늬 정정 (v2.0)

| 보스 | 실크 바탕/레이스 색 | 꽃무늬 신규 설정 |

꽃은 평면 자수/직조 무늬이며 새로 매달린 장신구·화관·입체 꽃 장식이 아니다. 주요 실크 패널은 불투명하게 유지하고 레이스는 가장자리·선택된 패널에 제한한다. 광택은 넓고 부드러운 면으로 표현하며 피부나 금속처럼 번들거리게 하지 않는다. 가터벨트/끈의 연결·클립·스타킹 높이와 접촉을 유지한다. 기존 스타킹 몸통 재질을 임의로 바꾸지 않으며 레이스 상단은 좁고 단정하게 적용한다. 모르가나는 기존 시스루 다리 착장 외관과 내장 지지 구조를 보존한다.

이번 이미지 수정은 아르델라 내부 의상 3뷰에만 시행했다. 다른 네 보스의 색·꽃은 후속 제작용 설정안으로 기록했으며 이미지는 생성하지 않았다. 새 첨부 파일은 작업용 전송에 실패하여 사용하지 않았고, 앞서 저장한 동일 아르델라 설정화 v2를 수정 대상으로 사용했다. 결과는 검토본이며 기존 파일을 덮어쓰지 않는다.

## 1. Anatomy Standard — 신체구조 기준

### 공통 작화 언어

현재 플레이어블·NPC에서 공통적으로 확인되는 방향은 성인 여성의 길고 정돈된 전신 비율, 작게 단순화된 얼굴, 연속적으로 연결되는 팔다리, 의상 아래의 입체적인 몸통이다. Karen·대장장이의 단단한 체형과 Iris의 작은 체격, 여관 주인의 풍부한 몸통처럼 개인차는 유지한다. 모두 같은 허리 폭이나 같은 가슴·골반 크기로 통일하지 않는다.

몸을 먼저 두개골, 흉곽, 골반과 관절 중심으로 구성한 뒤 의상을 입힌다. 코르셋·갑옷·치마의 외곽선을 골격으로 취급하지 않는다. 가슴은 흉곽 위의 연부조직이며 흉곽 자체를 대체하거나 팔의 부착 위치를 바꾸지 않는다.

| 항목 | 제작 기준 | 검수 방법 |
|---|---|---|
| Head/body ratio | 캐릭터 원본의 두개골 기준 등신 유지. 모자·왕관·올림머리·굽은 제외 | 정수리–턱 길이를 H로 잡고 맨발 신체 높이/H를 같은 투영 조건에서 비교 |

| Hands | 손바닥·엄지·손가락 관절이 장비를 실제로 감쌈 | 무기 없는 손과 파지 손의 크기, 손가락 수·겹침 확인 |

### 비율 기록 원칙

승인 원본의 정면 또는 약한 3/4 시점에서 H, 어깨 관절 간격/H, 흉곽 폭/H, 골반 폭/H, 상완·전완/H, 대퇴·하퇴/H, 손바닥/H를 기록한다. 가려진 관절은 ‘추정’, 투시가 큰 항목은 ‘측정 보류’로 표시한다. 전신 일러스트의 픽셀 높이만으로 실체 등신을 단정하지 않는다.

캐릭터를 작게 또는 크게 보이게 하려면 전체 체격과 화면 배치를 조정한다. 보스의 위압감을 만들기 위해 머리를 비정상적으로 줄이거나 허리와 다리를 길게 늘리지 않는다. 승인된 초자연적 형태가 있다면 그 예외를 별도로 명시한다.

### 첨부 신체 참고 자료 12장 분석 — B01–B12

2026-10-09 첨부된 신체 자료 12장을 직접 확인했다. B ID는 신체 참고 자료의 식별자로, 승인 캐릭터의 체형 변경 지시나 확정 비율을 뜻하지 않는다. 체적과 실루엣의 관찰은 활용하되 얼굴·헤어·의상·촬영/작화 스타일은 신체 기준에서 분리한다. 사진 형태 자료도 렌즈·거울·보정 여부를 확인할 수 없으므로 실측 자료로 취급하지 않는다.

### 신체 자료를 기존 기준에 적용하는 규칙

- **부위별 체적을 분리한다:** 흉부, 흉곽, 허리, 골반, 둔부, 허벅지, 종아리의 관찰 가능 여부를 각각 기록한다. B01·B02·B06·B09·B11·B12의 풍부한 몸통을 모든 캐릭터의 공통 체형으로 만들지 않는다. 체형 변경이 지정되면 변경 부위와 골격 연결·의상 치수의 보정을 구분해 기록한다.
- **흉부와 어깨 연결을 유지한다:** B04·B07·B10에서 참고할 수 있는 쇄골·겨드랑이·상완 연결을 기존 골격 검수에 연결한다. 흉부 체적을 흉곽 폭·목 길이·팔 부착 위치로 대체하지 않는다. 의복 밖 윤곽만으로 연부조직과 뼈를 확정하지 않는다.
- **하체는 확인 가능한 자료로 판단한다:** B03·B04·B05에서 대퇴–무릎–하퇴–발목 연결을 비교한다. B04의 신발, B03의 슬리퍼, B05의 저해상도 한계를 기록한다. 상반신 자료로 둔부·허벅지·다리 길이를 임의로 완성하지 않는다.
- **체형과 자세 효과를 구분한다:** B03의 팔 올림/골반 기울임, B09의 앉음, B10의 전방 기울임은 중립 자세의 실측 대체가 아니다. 2절에 따라 골반·흉곽·어깨 방향과 지지를 검수하며 외곽 S-curve 자체를 기준으로 삼지 않는다.
- **근육 표현은 보이는 범위만 기록한다:** B04·B05의 복부와 하지 명암은 표면 관찰에 한정한다. 조명·자세·연부조직 때문에 나타난 음영을 근육량 수치로 바꾸지 않는다. 이번 12장으로 부위별 근육량 척도를 확정하지 않는다.
- **승인 원본을 먼저 적용한다:** 이번 자료는 체형 다양성과 인체 연결을 확인하는 보조 자료다. 기존 캐릭터의 얼굴·헤어·의상·포즈는 체형 수치의 근거에서 제외한다. 캐릭터별 승인 비율과 체형 개성을 유지하고, 그림체는 승인 플레이어블/성역 NPC를 따른다.

## 2. Pose Standard — 포즈 기준

### 포즈 설계 순서

1. 지상 정지, 이동, 공격, 회피, 부유 중 무엇인지 지정한다.
2. 접지하는 발과 장비의 하중을 정한다. 바닥면과 발바닥 방향을 맞춘다.
3. 지지 다리 위에 골반을 놓고 반대 다리의 역할을 정한다.
4. 골반 기울기에 맞춰 척추·흉곽을 보정하고 어깨와 머리의 균형을 잡는다.
5. 어깨–팔꿈치–손목을 연결한 뒤 손과 무기를 배치한다.
6. 머리카락, 망토, 소매, 끈을 신체 움직임과 외력에 따라 배치한다.

Counter-balance는 모든 포즈에서 어깨와 골반을 기계적으로 반대로 기울이라는 뜻이 아니다. 직업·하중·움직임에 필요한 만큼만 보정한다. 허리 하나로 모든 회전을 처리하지 않고 흉추, 골반, 고관절의 분담을 보여준다.

| 상태 | 무게중심·지지 기준 | 허용되는 예외 |
|---|---|---|
| 지상 정지 | 발바닥과 두 발 사이가 이루는 지지 영역 안에 합성 무게중심 유지 | 손으로 벽·지팡이를 실제 지지할 경우 접점 포함 |
| 공격·돌진 | 추진 방향, 지지 발, 다음 접지 위치가 읽혀야 함 | 순간적으로 지지 영역 밖으로 이동 가능. 정지 자세 기준을 강요하지 않음 |
| 피격·후퇴 | 외력 방향과 반응이 연결됨 | 의도적 균형 상실 가능. 중립 자세로 오해되지 않도록 표현 |
| 부유·마법 | 발 접지를 강요하지 않음. 부유를 유지하는 힘과 신체축 명시 | 머리카락·옷을 같은 외력장에 종속시킴 |

칼·방패·도끼를 든 팔에는 손목과 팔꿈치의 지지 방향이 보여야 한다. 총기는 견착·손잡이·방아쇠 손가락·보조 손의 위치를 먼저 확인한다. 인형의 줄과 향로의 사슬은 장력과 중력을 구분한다. 무기가 몸을 관통하거나 손에서 떠 있으면 실패다.

동일 캐릭터의 포즈 변형에서는 관절 길이와 파지 위치를 유지한다. 방향 전환을 위해 단순 좌우 반전했을 때 문장, 비대칭 갑옷, 무기 손, 헤어 장식이 바뀌지 않는지 확인한다. 기존 플레이어 RIGHT-FACING·적 LEFT-FACING 규칙은 보존하며, 이 문서로 런타임 방향 로직을 수정하지 않는다.

### 기존 가이드에 연결하는 범위

P01은 2절의 동작 상태·접점, P02는 1절의 골격/관절 연결, P03는 2절의 회전 분담과 순간별 지지, P04는 기본 자세 선택과 9절의 포즈 반복 방지에 연결한다. 4장 모두에서 정확한 손가락 파지, 보스 무기 하중, 하이힐 접지, 헤어/의복 물리가 충분히 제공되지는 않는다. 해당 항목은 기존 승인 원본과 5·7절로 검수하고 이 자료로 확인됐다고 보고하지 않는다. 가려진 관절·인체 비율은 실측 완료로 처리하지 않는다.

## 3. Hairstyle Taxonomy — 헤어 구조 분류

### 이름 대신 독립 속성으로 저장

헤어 기록은 `길이 + 커트 구조 + 앞머리 + 옆머리 + 뒤머리 윤곽 + 묶음 방식 + 질감`으로 구성한다. Curtain bangs는 앞머리 속성이고, U/V cut은 뒤쪽 끝선 속성이다. Bun·ponytail은 묶음 방식이다. 이들을 상호 배타적인 커트 목록으로 취급하지 않는다. Hush·wolf·butterfly는 자료마다 경계가 다르므로 실제 층과 실루엣을 기록한다.

| 분류 | 시각 구조 | 접촉·질량·확인점 |
|---|---|---|
| Short/pixie | 짧은 정수리 덩어리와 귀·목 주변의 끊긴 외곽 | 귀 노출, 관자 잔머리, 후두부 볼륨과 목덜미 길이 |
| Bob | 턱·목 근처의 연속된 둥근 또는 각진 끝선 | 턱 옆 폭, 목 노출, 안쪽/바깥쪽 C 끝선, 후두부 두께 |
| Lob/medium | 쇄골·어깨에 닿는 길이, 하단이 어깨 영향 받음 | 어깨 위에서 휘거나 뒤로 넘어가는 접촉, 앞뒤 길이 차이 |
| Long straight | 길게 이어지는 큰 면, U/V/직선 끝선 | 등 뒤 주 질량, 어깨를 넘는 앞쪽 일부, 뿌리에서 끝까지의 중력 방향 |
| Long layers | 길이가 다른 층들이 큰 외곽 안에서 연결 | 짧은 얼굴 층과 긴 등 뒤 층의 비율, 끝선의 계단이 아닌 자연스러운 연결 |
| Wolf | 상대적으로 짧고 거친 상부 층 + 길게 남은 목덜미·하부 | 정수리 볼륨, 귀 주변 분리, 상하 질량 차이. 단순 긴 웨이브로 처리 금지 |
| Hush | 부드럽게 이어지는 경량 층과 얇은 얼굴 프레임 | 정수리 과팽창을 줄이고 끝의 가벼움·완만한 층 전환 기록 |
| Butterfly | 짧은 얼굴 프레임과 긴 후면의 두 길이군, 큰 C/S 흐름 | 앞쪽 양감과 뒤쪽 길이를 분리. 포즈마다 펼친 두 날개로 고정하지 않음 |
| Hime | 수평 앞머리·볼/턱 높이 옆단·긴 후면의 명확한 단차 | 옆단 끝 높이, 좌우 대칭 여부, 직선 면의 두께 |
| Shag | 여러 높이의 흐트러진 층과 질감 있는 끝 | 앞머리·관자·목덜미의 분리, wolf와 실제 길이 분포로 구별 |
| Wave/curl | C, S, 작은 컬, 큰 컬, 끝만 말림을 구분 | 곡률과 반복 간격, 밀도, 중력에 따른 풀림. 모든 가닥 동일 주기 금지 |
| High/mid/low pony | 뒤쪽 묶음 피벗에서 하나의 큰 질량이 내려옴 | 묶인 위치, 두피 당김 방향, 묶음 아래 중력 곡선 |
| Side/twin pony | 한쪽 또는 두 피벗으로 질량 분산 | 얼굴·무기와 충돌, 좌우 길이와 피벗 높이의 정체성 |
| Bubble pony | 하나의 꼬리에 간격을 둔 분절 묶음 | 묶음 사이 팽창, 각 구간 무게, 마지막 끝선 |
| Braid | 가닥이 교차하는 두께 있는 긴 구조 | 뿌리→중간→끝의 두께 변화. 프렌치·더치·피시테일은 교차 구조 확인 후 명명 |
| Crown/waterfall braid | 두피를 따라 둘러가는 묶음 또는 일부 가닥이 내려오는 구조 | 고정 경로, 남는 느슨한 질량, 정수리·귀 위 접촉 |
| Bun/chignon | 꼬리를 회전·접어 만든 응집된 덩어리 | 높이, 중심, 고정 방식, 목 노출, 빠져나온 잔머리 |
| Half-up | 상부만 고정되고 하부가 풀려 있음 | 상부 피벗과 하부 질량을 별도 기록. 전체 포니로 오인 금지 |

## 4. Hair Selection Rules — 캐릭터별 선택 규칙

신규 캐릭터는 길이, 정수리 윤곽, 앞머리, 묶음 피벗, 뒤쪽 질량 중 여러 축에서 기존 인물과 구별한다. 색상만 바꾼 동일 헤어를 다른 디자인으로 승인하지 않는다. 기존 캐릭터는 승인 헤어를 보존하며, 아래 표는 교체 제안이 아니라 유지할 구별 요소다.

| 플레이어 | 현재 자료에서 읽히는 구별 요소 | 포즈 적용 시 유지할 기준 |
|---|---|---|
| Bell | 금발 긴 후면, 얼굴 옆 비대칭 흐름, 단정한 기사 실루엣 | 어깨 갑옷·망토와 분리, 얼굴을 가리는 과도한 전면 덩어리 제한 |
| Seraphin | 마법사 모자 아래 긴 금발의 큰 굴곡과 측면 질량 | 모자가 누르는 정수리와 긴 하부를 구분, 지팡이와 충돌 방지 |
| Lumiera | 짧은 분홍 헤어, 측면의 응집된 둥근 윤곽 | 짧은 끝선·얼굴 노출 유지. 긴 웨이브로 변경 금지 |
| Verna | 어두운 녹색 장발, 뒤로 흐르는 비교적 절제된 덩어리 | 견착·시야·총기 손잡이를 가리지 않음 |
| Iris | 밝은 회색의 굴곡진 긴 헤어와 작은 체격 대비 | 줄·인형 팔과 머리카락의 앞뒤 관계 명확. 다른 캐릭터와 같은 대형 웨이브로 확대하지 않음 |
| Karen | 붉은 거친 흐름과 일부 땋기, 강한 체격 | 어깨 털·방패·도끼와 각각 독립된 윤곽을 유지 |
| Ire | 검은 높은 올림 묶음과 긴 후면 | 높은 피벗·두피 당김·하부 무게를 구분. 팔 회전에 따라 일부 머리 질량이 이동 |

성역 NPC도 직업 도구와 헤어가 연결되어야 한다. 대장장이는 작업 중 시야와 도구 접근성이 우선이며 현재 묶음과 고글을 유지한다. 상인·접수원·여관 주인의 응집된 묶음과 장식은 각각 유지한다. 연금술사·마법부여사·고해사제의 긴 머리는 색뿐 아니라 가르마·장식·굴곡·옷과의 겹침으로 구분한다.

캐릭터별 헤어 카드는 성격, 직업, 장비, 전투 방식, 사회적 위치, 세계관 의미를 함께 기록한다. 귀족이라는 이유만으로 모두 큰 컬, 전사라는 이유만으로 모두 포니를 지정하지 않는다. 역할은 실용 조건이며 승인 디자인을 대체하는 자동 규칙이 아니다.

앞머리도 실루엣 차별화 항목이다. 신규 디자인에서 동일한 앞머리를 일괄 반복하지 않고 가르마·밀도·길이·이마 노출을 대조한다. 근거는 3절 R02의 동일 앞머리 반복을 기준으로 채택하지 않는 제한, 본 절의 여러 축 구별 원칙, 부록 B의 Bangs 기록 항목이다. 이미 승인된 캐릭터의 앞머리를 중복 방지만을 이유로 교체하지 않는다.

## 5. Hair Physics Rules — 일러스트의 헤어 물리

뿌리는 두피에 고정되어 있고 중간은 목·어깨·등·장식과 접촉하며 끝은 무게와 외력에 따른다. 한 장의 정지 이미지에서도 이 연결이 보여야 한다.

| 상황 | 뿌리 | 중간 | 끝 |
|---|---|---|---|
| 정지 | 가르마와 두개골 곡면을 따름 | 목/어깨를 타고 내려가거나 등 뒤로 떨어짐 | 바람 없으면 중력 방향 우선 |
| 몸통 회전 | 두피·묶음 피벗과 함께 이동 | 이전 방향에 일부 남아 곡선 형성 | 회전 진행 방향·순간을 고려한 뒤따름 |
| 바람 | 고정점 유지 | 접촉에서 벗어나는 양만큼 흐름 | 같은 바람장 안의 천·끈과 방향 일관 |
| 마법·부유 | 고정점 유지 | 국소 또는 전역 외력의 적용 영역 명시 | 부유 원인이 있는 구간만 들림 |
| 묶음/땋기 | 묶인 위치에서 장력 | 풀린 헤어보다 응집되고 굴곡이 제한됨 | 굵기가 감소하며 무게에 맞는 처짐 |

Root→mid→tip 지연은 일러스트의 순간을 설명하는 기준이다. 이번 문서에서 애니메이션이나 Living Idle 코드를 구현하지 않는다. 머리카락의 모든 끝을 같은 각도로 반복하지 않고 큰 질량 2–4개 수준에서 먼저 흐름을 설계한 뒤 내부 가닥을 나눈다. 이 개수는 작업 편의를 위한 제안이며 승인 원본의 가닥 수를 바꾸라는 규칙이 아니다.

팔·총·칼·사슬·인형 줄과 교차할 때는 어느 것이 앞인지 명확하게 한다. 접촉하는 머리카락이 어깨나 갑옷을 통과하면 안 된다. 중력만 작용하는 머리카락을 양옆으로 동시에 펼친 장식처럼 그리지 않는다. 기존 승인 원본에 표현된 흐름은 존중하되, 새로운 포즈에서는 움직임의 원인을 기록한다.

## 6. Costume Preservation Rules — 의상 정체성 보존

기존 캐릭터를 수정하기 전에 의상 실루엣, 주색/보조색, 무기, 문장, 서명 장식, 노출 영역, 소재를 잠금 목록으로 만든다. 그림체를 맞춘다는 이유로 보스의 옷을 플레이어의 옷으로 바꾸지 않는다.

| 유지 | 허용되는 구조 교정 | 금지 |
|---|---|---|
| 코트·드레스·갑옷의 디자인 | 신체에 맞는 치수, 관절에 맞는 판 위치 | 새로운 드레스, 갑옷 삭제, 노출도 변경 |
| 색 배치·문장·장식 | 조명에 따른 명도, 투시·가림에 맞는 위치 | 팔레트 교체, 문양 재설계, 장식 무단 추가 |
| 봉제·벨트·끈의 역할 | 당김점·접촉점·주름 교정 | 끈이 몸에 고정되지 않거나 지퍼/봉제선이 관절을 무시 |
| 무기와 액세서리 | 파지·투시에 맞는 길이/크기의 제한된 보정 | 무기 종류 교체, 서명 액세서리 제거 |

가슴·허리·골반 주변 주름은 실제 봉제, 조임, 하중에서 생겨야 한다. 천 아래 몸을 설명하려고 모든 부위를 밀착 윤곽으로 그리지 않는다. 두꺼운 갑옷은 피부처럼 휘지 않고, 판 사이 연결부에서 관절 움직임을 수용한다.

## 7. Weapon Scale Rules — 무기 크기와 하중

무기 크기는 캐릭터 승인 원본을 기준으로 기록한다. 칼 전체 길이/H, 손잡이 길이/손바닥, 방패 높이/몸통, 총 개머리판–어깨 접점, 지팡이 높이/신장처럼 기능에 맞는 비교를 사용한다. 화면상 길이만으로 원근 단축을 실제 축소로 오판하지 않는다.

검은 손이 손잡이를 감싸고 가드가 손 위치를 지지해야 한다. 도끼는 날의 무게가 손목·팔꿈치·어깨의 하중으로 연결되어야 한다. 방패는 들고 있는 손이나 스트랩 고정점을 기록한다. 총은 견착과 팔 길이에 맞아야 하며, 마법 지팡이도 손에서 떠 있지 않아야 한다. 향로·줄·사슬은 매단 점과 끝의 하중을 표시한다.

성역 NPC의 망치·쟁반·책·병도 같은 원칙을 적용한다. 쟁반의 합성 무게중심을 지지 손과 연결하고 책의 두께와 손가락 벌림을 맞춘다. 장식만으로 읽히는 도구도 파지 구조를 생략하지 않는다. 대형 무기는 승인된 크기를 유지하되 무게를 지지하는 포즈나 세계관상의 힘을 명시한다.

## 8. Rendering / Art Style Rules — 그림체 기준

현재 플레이어·NPC의 공통 방향은 **회화적 음영을 갖춘 정교한 판타지 전신 일러스트와 절제된 애니메이션형 얼굴**이다. 얼굴은 비교적 단순하고 옷·장비는 세밀하다. 사진형 헤어 레퍼런스는 구조만 참고하고 사진 피부·실사 얼굴을 적용하지 않는다. 보스의 기존 의상을 플레이어 의상으로 교체하지 않고 이 묘사 체계에 맞춘다.

| 항목 | 통일할 표현 | 실패 판정 |
|---|---|---|
| 얼굴 | 승인 캐릭터별 눈 간격·턱·코 길이를 보존, 같은 수준의 단순화 | 보스만 실사 얼굴 또는 과도하게 큰 눈·극소 코 |
| 눈 | 위 눈꺼풀, 홍채, 하이라이트의 밀도를 주변 얼굴과 균형 | 보스의 눈만 발광 보석처럼 과세부, 좌우 눈의 투시 불일치 |
| 코/입 | 작은 면 변화와 절제된 선, 캐릭터 표정 유지 | 입술만 사진 수준 질감, 턱과 입의 부착 위치 붕괴 |

3. 분노를 매번 크게 벌린 입, 웃음을 매번 감긴 눈, 걱정을 매번 눈물로 반복하지 않는다. E02–E04에서 보이는 같은 감정 범위의 강도와 시선 차이를 이용하되 감정 이름만으로 고정 표정을 지정하지 않는다.
4. 고개 회전·기울기·원근과 감정 변화를 구별한다. 측면의 가려진 눈과 입 반대쪽을 임의로 대칭 복원하지 않는다. 머리 각도가 달라져도 눈·코·입이 같은 두개골에 붙어 있어야 한다. 근거: E02 측면, E03 측면·3/4, E04의 여러 각도와 1절 투영 비교 원칙.
5. 비대칭 표정은 눈썹·눈꺼풀·입꼬리의 의도적인 차이로 기록한다. 시트의 모든 비대칭을 해부학 오류 또는 교정 대상이라고 단정하지 않는다. 근거: E03–E04.
6. 홍조·땀·눈물·효과선은 보조 신호다. 표정의 눈·입 구조와 상황이 먼저 읽혀야 한다. 흑백 얼굴 채움·초대형 눈/입 등 만화적 과장을 8절의 부드러운 피부 음영·절제된 얼굴 대신 적용하지 않는다.
7. 플레이어·NPC·보스마다 승인된 인상·성격·장면에 맞는 강도를 선택한다. 참고 인물의 미소·분노 얼굴을 5보스에 동일하게 붙이지 않는다. 기존 눈가리개·베일 등 가림 요소를 표정 전달을 이유로 제거하지 않고 보이는 얼굴 부위와 머리 자세로 제한해 표현한다. 특정 보스의 새 표정이나 의상 변경을 이번 자료 분석만으로 승인하지 않는다.

### 기존 보존·렌더링 규칙에 연결

- **겹침과 두께:** C02·C08·C20처럼 안쪽 옷, 몸통 패널, 벨트, 갑옷의 앞뒤를 먼저 표시한다. 6절의 원본 층 순서와 갑옷 형태를 유지하며 접촉 그림자·간격으로 두께를 표현한다.
- **주름의 원인:** C03·C06·C12·C17·C18에서 보이는 커프스, 단추선, 허리 고정, 관절 굽힘을 구분한다. 고정점의 당김·접촉의 압축·자유 자락의 중력 주름을 선택하고 신체 윤곽 전체에 주름을 반복하지 않는다.
- **앞뒤 연결:** C05·C14·C19·C20의 양면 그림은 끈·허리띠·자락의 대응을 확인하는 참고다. 자료별 시점이 완전히 일치한다고 가정하거나 보이지 않는 봉제와 치수를 확정하지 않는다.
- **소재 표현:** C01·C04·C11·C16·C20의 시스루, 러플, 니트, 금속을 구분하되 8절의 프로젝트 렌더링 밀도를 따른다. 피부·천·가죽·금속에 같은 하이라이트를 적용하지 않는다. 원본에 없는 시스루·레이스·광택을 추가하지 않는다.
- **매달린 부속:** C04·C05·C14·C19의 체인·주머니·끈은 고정점에서 이어지고 중력·몸/옷 접촉을 받게 한다. 7절에 따라 무기는 승인 원본을 유지하며 장식/검집과 파지 손의 관계를 별도로 검수한다.
- **신체와 의상:** 의복 외곽과 과장된 밀착 표현으로 골격을 결정하지 않는다. 1·2절로 신체·지지·관절을 구성한 뒤 6절에서 허용한 치수·패널 위치·자락 흐름을 조정한다. 외부 자료의 노출·체형으로 승인된 의상 정체성을 변경하지 않는다.

### 가터·스타킹·치마·허벅지 접촉의 적용 규칙

1. **구조를 먼저 구분한다.** 가터벨트는 허리/골반 지지부, 가터끈은 세로 연결부, 스타킹 상단띠는 다리 착장 가장자리다. 독립 허벅지 밴드·장식 금속띠·갑옷 경계는 별도 항목이다. C29처럼 다른 상의에서 직접 연결된 구조도 있으므로 모든 세로끈을 같은 허리벨트에 연결하지 않는다.
2. **연결은 보이는 근거를 따른다.** C22·C27·C32·C40의 고정점→끈→조절부/클립→상단 경로를 기록한다. 포즈에 맞는 길이와 당김을 조정하되 끈이 살·옷을 관통하거나 고정 없이 떠 있지 않게 한다. 치마에 가려진 위쪽 고정은 ‘가림’으로 남긴다.
3. **스타킹 재질을 분리한다.** C21·C22·C32의 얇은 몸통, 진한 상단띠, 레이스 테두리와 C31·C34의 망사, C25·C26의 불투명/단단한 다리 착장을 구분한다. 망사 격자는 허벅지 곡면·원근을 따르고 레이스 구멍과 큰 무늬를 혼동하지 않는다. 그림의 광택만으로 원단 성분이나 데니어를 확정하지 않는다.
4. **치마 형태를 보존한다.** C24의 모인 자락, C32·C33의 짧은 치마, C35–C37의 옆 트임/드레이프, C38의 중앙 패널을 각각 기록한다. 주름은 허리 고정·패널 겹침·움직임에서 설명하며 기존 승인 치마 길이·트임·노출 범위를 임의로 바꾸지 않는다.
5. **눌림은 국소 접촉으로 표현한다.** C31의 뚜렷한 경계 굴곡, C32의 완만한 경계, C37·C38의 명확하지 않은 눌림처럼 자료별 차이를 보존한다. 기록은 ‘판독 불가 / 뚜렷한 변화 없음 / 약한 단차 / 뚜렷한 굴곡’의 정성 관찰로 제한한다. 실제 압력·퍼센트·mm·1–100 척도로 환산하지 않는다.
6. **관절과 전체 체적을 유지한다.** 띠 주변의 작은 외곽 변화와 접촉 그림자 때문에 대퇴가 끊기거나 골격이 좁아지지 않게 한다. 밴드 위아래 전체 허벅지를 확대하는 방식으로 눌림을 표현하지 않는다. C33의 앉은 압축과 C31의 띠 접촉, 원근 효과를 구분한다. 금속 장식과 탄성 밴드에 같은 변형을 적용하지 않는다.
7. **승인 원본의 존재 여부가 먼저다.** 기존 가터·스타킹·치마·밴드가 있는 캐릭터의 연결/핏/재질 교정에 사용한다. 참고 자료만을 이유로 새 가터벨트·속옷·트임·장식·무기 또는 노출을 추가하지 않는다. 외부 로고·인물·복식을 그대로 이식하지 않는다.
